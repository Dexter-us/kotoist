Kotoist API

Host functions, MIDI pattern fields, scale catalog, helper methods, and bundled random module.

Koto 0.15.1 · Kotoist 0.2.9

Kotoist embeds Koto 0.15.1, adds the kotoist module, imports random, and loads its local pattern.koto library.

MIDI pattern map defaults

midiout(pattern_or_list, quantization) schedules MIDI from one pattern map or a list of maps. Quantization is in beats. Defaults are from the v0.2.9 parser.

KeyDefaultMeaning
dur1.0Inter-event duration in beats
length1.0Note length / gate duration
degree0Scale degree(s) or rest values
scalechromaticScale name; case-insensitive
root0Root MIDI pitch offset
transpose0Chromatic transposition
mtranspose0Scale-relative transposition
octave5Octave offset; source clamps octave contribution to 0–120 semitones
channel0MIDI channel value
amp0.85Amplitude mapped to MIDI velocity (0–127)

Use print_scales() to print all available scales in the plugin console.

Kotoist utility API

Utility API

midiout

Plays the pattern.

midiout {}, 4
ArgumentDescriptionDefault
patternA pattern or an array of patterns to play.
quantizationThe quantization in beats.

The pattern is a map with optional values:

  • dur - note duration
  • length - note length
  • degree - step in the scale
  • scale - case-insensitive, to view available scales execute print_scales

function

  • root - root note
  • transpose - simple transpose
  • mtranspose - transpose relating to the scale
  • octave - octave number (from 0)
  • channel - MIDI channel number
  • amp - amplitude (from 0.0 to 1.0)

on_load

Executes a callback function when plugin initialized.

on_load ||
    print "plugin loaded"
ArgumentDescriptionDefault
callbackA function, which will be called, when plugin initialized.

on_midiin

Executes a callback function when host sends MIDI note-on/off events.

on_midiin |note, velocity, channel|
    if velocity == 0
        print "note off: ", note
    else
        print "note on: ", note
ArgumentDescriptionDefault
callbackA function, receiving note_number (integer [0, 127]), velocity (float [0.0, 1.0]) and channel (integer [0, 127]).

on_midiincc

Executes a callback function when host sends MIDI control change message.

on_midiincc |cc, value, channel|
    print "control: ", cc, ", value: ", value
ArgumentDescriptionDefault
callbackA function, receiving control_number (integer [0, 127]), value (float [0.0, 1.0]) and channel (integer [0, 127]).

on_play

Executes a callback function when playback is started.

on_play |beat_pos, tempo|
    print "playing", beat_pos, tempo
ArgumentDescriptionDefault
callbackA function, receiving the current beat position and tempo, when playback is started.

on_pause

Executes a callback function when playback is paused.

on_pause |beat_pos, tempo|
    print "paused", beat_pos, tempo
ArgumentDescriptionDefault
callbackA function, receiving the current beat position and tempo, when playback is paused.

Bundled random module

Utilities for generating random values in Koto.

At the core of the module is the Rng type, which is a seedable random number generator. Each thread has access to a generator with a randomly selected seed, or unique generators can be created with KOTOTOKENX1X.

bool

|| -> Bool

Generates a random bool using the current thread's generator.

Example

# Seed the thread Rng so that we get predictable results
random.seed 99

print random.bool()
# Expected output: false
print random.bool()
# Expected output: true

generator

|| -> Rng

Creates an KOTOTOKENX0X with a randomly generated seed.

|Number| -> Rng

Creates an KOTOTOKENX0X with a specified seed.

Example

rng = random.generator 99
print rng.pick (1, 2, 3)
# Expected output: 3
print rng.bool()
# Expected output: false

number

|| -> Number

Generates a random number using the current thread's generator.

The number will be a floating point value in the range from 0 up to but not including 1.

Example

# Seed the thread Rng so that we get predictable results
random.seed 123

# Print random floats up to 3 decimal places
print '{random.number():.3}'
# Expected output: 0.853
print '{random.number():.3}'
# Expected output: 0.168

pick

|Indexable| -> Any?

Selects a random value from the input using the current thread's generator.

  • If the input is empty, then null will be returned.
  • If the input is a map, then a tuple containing the key and value of a

randomly selected entry will be returned.

  • If the input is a range, then the result will be an integer within the given

range.

  • If the input is some other indexable type (like a list or tuple),

then a randomly selected element from the input will be returned.

Example

# Seed the thread Rng so that we get predictable results
random.seed -1

print random.pick (123, -1, 99)
# Expected output: 99
print random.pick 10..20
# Expected output: 14
print random.pick {foo: 42, bar: 99, baz: 123}
# Expected output: ('bar', 99)
print random.pick []
# Expected output: null

seed

|Number| -> Null

Seeds the current thread's generator so that it produces predictable results.

Example

from iterator import generate
from random import pick, seed

# Returns a tuple containing three numbers from 1 to 10
pick_3 = || generate(3, || pick 1..=10).to_tuple()

seed 1
print pick_3()
# Expected output: (5, 3, 8)

seed 2
print pick_3()
# Expected output: (6, 9, 3)

seed 1
print pick_3()
# Expected output: (5, 3, 8)

shuffle

|Indexable| -> Any

Reorders the entries in a container so that they have a new randomly shuffled order, and returns the container.

from random import seed, shuffle

x = [1, 2, 3, 4, 5]

seed 2
print shuffle x
# Expected output: [4, 1, 2, 3, 5]
print shuffle x
# Expected output: [5, 2, 4, 3, 1]

y = {a: 1, b: 2, c: 3}
print shuffle y
# Expected output: {b: 2, a: 1, c: 3}
print shuffle y
# Expected output: {a: 1, c: 3, b: 2}

Rng

Rng is the random module's core random generator.

The ChaCha algorithm with 8 rounds from the rand_chacha crate is used to generate random values. See the implementation's docs for more information.
