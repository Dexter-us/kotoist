A multi-page reference for the Koto language and Kotoist-specific MIDI API, patterns, and Windows CLI.

Koto 0.15.1 · local HTML documentation

Scope: The language guide and core library reference match Koto 0.15.1, the version used by Kotoist v0.2.9. This includes the Kotoist host API, bundled random module, local pattern library, supported scales, and MIDI command-line exporter. Optional Koto packages not registered by Kotoist are not presented as built-ins.
