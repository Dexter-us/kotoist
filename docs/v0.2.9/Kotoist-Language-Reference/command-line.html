Command-line MIDI

CLI syntax, limits, output behavior, and how bars and tempo determine export duration.

Koto 0.15.1 · Kotoist 0.2.9

The Windows command-line exporter uses the same Koto interpreter and pattern scheduler as the VST3. It writes a Standard MIDI File; it does not render audio.

Command syntax

kotoist.exe midi input.koto output.mid [--bpm 120] [--bars 4]

Defaults: --bpm 120 and --bars 4. BPM range: 1–1000. Bar count: 1–256. Each export is limited to 10 minutes; a script with no MIDI notes reports an error.

Choosing a duration in seconds

There is currently no --seconds option. The CLI selects whole 4/4 bars at a tempo:

seconds = bars × 4 beats per bar × 60 ÷ BPM
SettingsApproximate length
--bars 4 --bpm 1208 seconds
--bars 8 --bpm 12016 seconds
--bars 2 --bpm 608 seconds

At 120 BPM, 6 seconds is 3 bars and 10 seconds is 5 bars. This is a whole-bar approximation, not a direct exact-seconds setting.

Example

Create test.koto:

midiout({degree: 0}, 0)

Then export four bars:

kotoist.exe midi "test.koto" "test.mid" --bpm 120 --bars 4

Open test.mid in a DAW or MIDI editor and route it to an instrument to hear it.

CLI package notes

Kotoist MIDI command-line exporter

The Windows MIDI CLI uses the same Koto interpreter and pattern scheduler as the plugin. It writes a one-track Standard MIDI File; it does not render audio.

Usage

kotoist.exe midi input.koto output.mid [--bpm 120] [--bars 4]

Defaults are 120 BPM and four bars of 4/4. The bar count can be set from 1 to 256. A single export is limited to 10 minutes.

Example

The included midi-export-demo.koto file emits a repeating MIDI note. From the extracted CLI folder, run:

kotoist.exe midi midi-export-demo.koto demo.mid --bpm 120 --bars 4

The source script may use the same Kotoist midiout patterns as the VST. The generated file can be opened in a DAW or another MIDI editor.
